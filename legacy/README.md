## 一、为什么下线

原方案(第 3 步)的做法是: 在 YOLO 框内裁剪 ROI → 上采样 → **成对边缘的匹配滤波**
逐行找左右轮廓边 → 对左右边中点做 IRLS 鲁棒直线拟合 → 斜率即筒身轴线方向。

它建立在两条物理先验上: 左右轮廓边**互相平行**、且两条边的**间距(筒身投影宽)恒定**。
问题出在"哪两条边属于同一根筒子"这件事上 —— 落地段 ROI 里同时存在箭体 / 展开的
支腿 / 着落坪边缘 / 高亮蒸汽带, 实测左右边拟合出的不平行度达 2°(直筒理论应为 0°)。

**更致命的不是精度, 而是它量错了对象**: 原方案拟合出的"条带"实际落在**涂装条纹**
上, 而不是筒身轮廓(见下面的 w_body 一行)。用**表面特征**去代表**轴线**, 会引入
视角相关的角度偏差 —— 这正是两条路线之间存在系统性偏移的根源。

## 二、关键对比数据(冻结于下线当日, 不再复现)

| 指标 | 原方案(梯度边缘) | **SAM 2.1 @512** | **SAM 2.1 @1024** |
|---|---|---|---|
| 旋转增益(理想 1.0) | 0.898 | 0.963 | **0.975** |
| 增益帧间 σ | — | 0.061 | **0.018** |
| 帧内残差 σ | 0.187° | 0.091° | 0.091° |
| 落地静止段 46-66s σ | 0.223° | 0.095° | **0.059°** |
| `w_body` 口径 | ❌ 量到**涂装条纹**(≈0.5×框宽) | ✅ 剪影轮廓(≈0.85×框宽) | ✅ 同左 |
| 测角有效帧 | 907 | 1730 | 1741 |
| 全片耗时 | 33 s(纯 CPU) | 110 s(热抽帧)/173 s | 315 s |
| 落地段绝对 φ 中位 | −0.42°±0.22° | +0.43°±0.10° | +0.46°±0.06° |

**系统性偏移**: Δφ = SAM − 原方案。全片中位 **+0.76°**; 落地段(46-66s)
由两侧绝对量相减得 **+0.85°**(+0.43 − (−0.42))。两者口径自洽。

**物理原因**(不是标定问题, 而是原理问题): 圆柱面上的一条纵向母线, 在斜视角下的
**投影并不平行于剪影边缘**。所以用"间距恒定 + 平行"去挑表面条纹, 挑出来的方向
天然带一个视角相关的偏置; 而剪影左右边界的中点连线 = 轴线投影, 是几何恒等式
(箭体是回旋体), 不需要任何先验。这就是掩码路线的原理优势。

**结论**: 原方案不是"调参没调好", 而是**先验本身不成立**。它在落地段(目标大、
对比强)能给出不错的精度, 但一旦目标变小(前 25s 箭体只有 21×53 px、拟合条带
仅 7~10 px)就迅速退化 —— 有效帧只有 907/2203。这使它**不具备工程实用性**。
